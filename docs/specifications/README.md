# WebAXP Specifications

This directory contains detailed specifications for the WebAXP framework. These specifications define the architecture, components, and behavior of WebAXP applications.

## Core Specifications

- [Architecture](./ARCHITECTURE.md): The overall architecture of WebAXP applications
- [State Management](./STATE-MANAGEMENT.md): The state management system
- [Routing](./ROUTING.md): The routing system
- [API Integration](./API-INTEGRATION.md): The API integration system
- [PWA](./PWA.md): Progressive Web App features
- [CLI](./CLI.md): Command Line Interface for WebAXP

## Architecture

The [Architecture](./ARCHITECTURE.md) specification defines the overall structure of WebAXP applications, including:

- Core components (jcule, jellicule)
- Interaction flow
- Technology choices
- Implementation guidelines

## State Management

The [State Management](./STATE-MANAGEMENT.md) specification defines the state management system for WebAXP applications, including:

- Centralized store
- Reactivity
- Multi-tab synchronization
- Persistence
- Middleware

## Routing

The [Routing](./ROUTING.md) specification defines the routing system for WebAXP applications, including:

- Declarative routing
- Code splitting
- Navigation
- Route matching
- Route transitions

## API Integration

The [API Integration](./API-INTEGRATION.md) specification defines the API integration system for WebAXP applications, including:

- API client generation
- Declarative API integration
- State integration
- Offline support
- Authentication

## PWA

The [PWA](./PWA.md) specification defines the Progressive Web App features for WebAXP applications, including:

- Service worker
- Web app manifest
- Offline experience
- Installation experience
- App shell architecture

## CLI

The [CLI](./CLI.md) specification defines the Command Line Interface for WebAXP, including:

- Creating new applications
- Generating components
- Building applications
- Testing applications
- Deploying applications
